Background music
================
Any .mp3, .ogg or .wav file in this folder is played, one after the other (a single song loops).
To add a song: copy the file into this folder. To remove one: delete it.

childhood.mp3 - "Childhood" by Daniel (2:09).
IMPORTANT: only put music in the game that you made, or that you have permission or a licence to use.
If you share or publish the game, write who made each song in this file and in the game's description.
